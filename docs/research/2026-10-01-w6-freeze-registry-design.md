## 1. Recommendation

One command, `#whatwg_freeze`, declared in one new listed metaprogramming
module `WhatwgTest/Audit/Freeze.lean`. A battery line reads

```lean
#whatwg_freeze (@Whatwg.Streams.Writable.size_eq :
  Whatwg.Streams.Writable.Size = Whatwg.Streams.Data.DyadicSize)
  axioms [] anchor "SIZE"
```

so the ascription text of today's `#check (@n : T)` is kept byte for byte and
only the command word changes. The command elaborates `T` alone, with no
expected type, and refuses it if any metavariable is left (a hole cannot pin
anything); it then compares `T` with the constant's declared type by
alpha-equivalence (`Expr.eqv`, binder names and binder annotations ignored),
compares the exact axiom set from `Lean.collectAxioms` with the listed one,
and records an entry in a persistent environment extension. It prints nothing
on success. Clause keywords are non-reserved (`&"axioms"`), so the module adds
exactly one token to the table.

The declaration snapshot (D47) is generated by an executable,
`whatwg_declsnapshot`, that imports the built `.olean` files as `leanchecker`
does, reads every constant under `Whatwg` and every registry entry, joins
them with authored record rows, and writes `generated/declarations.tsv`; its
drift gate regenerates and compares bytes. An executable reads what Lake
tracks for it, which addresses D49 for this gate.

Masks become data: a three-constructor type in the freeze module, `m1`, `m2`
and `unmasked` with a reason, named so it cannot be confused with
`Effects.Trace.Mask`.

Conversion (provisional): convert every `#check (@n : T)` battery
mechanically in one builder slice, under a ruling that names the change, with
a before/after dump that shows every ascription's text and elaborated
statement unchanged. The `#print axioms` reports become redundant and are
retired by the same ruling.

Order of work: breaker packet (contract, red battery, gate addendum), then
builder slice 1 (the command and the list entry), slice 2 (the snapshot
executable), slice 3 (the battery conversion), reviewer, landing. W6 can land
before W7; W7 points evidence at registry entries.
